# مواقع الاستضافة والنسخ الاحتياطية وتقييم متطلبات الإقامة

**التاريخ** 2026-11-12

| المكوّن | الموقع الحالي | البيانات |
|---|---|---|
| قاعدة البيانات (Firebase RTDB) | بلجيكا · europe-west1 | الحجوزات، العملاء، أرقام الهوية، السجل |
| النسخ الاحتياطية اليومية | Google Drive لمالك السكربت | نسخة كاملة من القاعدة |
| مستندات العملاء | Google Drive لمالك السكربت | الهويات والعقود (PDF) |
| الموقع | GitHub Pages | كود فقط |
| البريد | Resend (الولايات المتحدة) | بريد العميل واسمه |

## التقييم
- البيانات الشخصية تُعالج خارج المملكة، وهذا يستلزم استيفاء لائحة نقل البيانات الشخصية خارج المملكة (نظام حماية البيانات الشخصية) أو نقلها لاستضافة داخل المملكة.
- الحسابات شخصية لا مؤسسية، وهذا يضعف الملكية والتحكم.

## الخيارات
1. **النقل لمنطقة الدمام** (Google Cloud me-central2): قاعدة Realtime Database الحالية لا تتوفر في هذه المنطقة، فيلزم الانتقال إلى Firestore في الدمام (إعادة كتابة طبقة البيانات في الموقع والسكربت)، ونقل المستندات والنسخ إلى Cloud Storage في نفس المنطقة.
2. **الإبقاء مع ضوابط النقل**: توثيق الأساس النظامي للنقل، وتقليل البيانات المرسلة (عدم تخزين صور الهوية إن لم تلزم)، وتوقيع شروط المعالجة.

**القرار المطلوب من الراعي:** اختيار أحد الخيارين قبل الربع الأول 2027 (سجل المخاطر R-01).
